# msf - Video Editor
تطبيق ويب مفتوح المصدر لتعديل الفيديوهات من الهاتف المحمول مباشرة.

## المميزات الحالية:
- رفع وتشغيل الفيديوهات محلياً من ذاكرة الهاتف.
- واجهة مستخدم بسيطة وخفيفة.

## كيفية التشغيل محلياً:
1. قم بفتح المستودع عبر متصفح الهاتف أو حاسوبك.
2. شغل ملف `index.html` في أي متصفح ويب حديث.
